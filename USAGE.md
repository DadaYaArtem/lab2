# Инструкция по использованию системы управления пиццерией

## Запуск программы

```bash
cd out/production/lab2
java com.pizzeria.Main
```

## Интерактивное меню

При запуске программа отображает главное меню с следующими опциями:

### 1. Регистрация/Вход клиента
- **Регистрация нового клиента**: Введите имя, фамилию, телефон и email
- **Вход как существующий клиент**: Выберите клиента из списка

Каждому клиенту автоматически создается карта лояльности с бонусными баллами.

### 2. Просмотр меню
Отображает доступные продукты по категориям:
- **Пиццы** (разных размеров: маленькая, средняя, большая)
- **Напитки** (Кока-кола, соки, вода)
- **Десерты** (Тирамису, чизкейк)
- **Закуски** (крылышки, салаты)

### 3. Создать заказ
1. Войдите как клиент (если еще не вошли)
2. Выберите "Создать заказ"
3. Добавьте товары:
   - Выберите товар по номеру
   - Укажите количество
4. Опционально:
   - Примените промокод (PIZZA10, PIZZA20, VIP30)
   - Укажите адрес доставки

### 4. Просмотреть текущий заказ
Показывает детали вашего текущего заказа:
- Список товаров с количеством
- Сумма товаров
- Скидка (если применена)
- Стоимость доставки
- Итоговая сумма

### 5. Оплатить заказ
Выберите способ оплаты:
- **Наличные**: Введите внесенную сумму, система рассчитает сдачу
- **Банковская карта**: Введите номер карты
- **Онлайн оплата**: Введите email для чека

После оплаты:
- Начисляются бонусные баллы (10 руб = 1 балл)
- Печатается чек
- Организуется доставка (если указан адрес)

### 6. Управление пиццерией (для менеджера)
Административные функции:
- **Просмотр сотрудников**: Список всех сотрудников с зарплатами
- **Проверка инвентаря**: Состояние запасов ингредиентов
- **Пополнить запасы**: Добавление ингредиентов на склад
- **История заказов**: Все выполненные заказы

### 7. Статистика
Общая информация о пиццерии:
- Количество сотрудников
- Количество клиентов
- Всего заказов
- Общая выручка
- Стоимость инвентаря

### 0. Выход
Закрывает пиццерию и завершает работу программы.

## Примеры использования

### Пример 1: Создание заказа с доставкой

1. Выберите `1` - Регистрация клиента
2. Введите данные:
   - Имя: Иван
   - Фамилия: Петров
   - Телефон: +79991234567
   - Email: ivan@example.com
3. Выберите `3` - Создать заказ
4. В меню добавления товаров:
   - `1` - Показать меню и добавить товар
   - Выберите номер пиццы (например, `2` - Маргарита средняя)
   - Количество: `2`
   - Добавьте напиток (например, `10` - Кока-кола)
   - Количество: `2`
5. Выберите `3` - Указать адрес доставки
   - Улица: Ленина
   - Дом: 25
   - Город: Москва
   - Индекс: 102000
   - Квартира: 42
6. Выберите `0` - Завершить добавление
7. Выберите `5` - Оплатить заказ
8. Выберите способ оплаты (например, `2` - Банковская карта)
9. Введите номер карты: `4532123456789012`

### Пример 2: Применение промокода

При создании заказа:
1. Добавьте товары в заказ
2. Выберите `2` - Применить промокод
3. Введите промокод: `PIZZA20`
4. Скидка 20% будет применена к заказу

Доступные промокоды:
- **PIZZA10** - скидка 10%
- **PIZZA20** - скидка 20%
- **VIP30** - скидка 30%

### Пример 3: Управление запасами

1. Выберите `6` - Управление пиццерией
2. Выберите `2` - Проверка инвентаря
3. Просмотрите состояние запасов
4. Если есть низкие запасы, выберите `3` - Пополнить запасы
5. Введите название ингредиента (например, "Моцарелла")
6. Введите количество (например, `50`)

## Технические детали

### Архитектура
Система реализует полный стек ООП с применением:
- **SOLID принципы** - разделение ответственности, открытость для расширения
- **GRASP паттерны** - Information Expert, Creator, Controller
- **Design Patterns** - Factory, Strategy
- **80+ классов** - полная объектная модель
- **12 персональных исключений** - обработка ошибок
- **6 интерфейсов** - абстракция поведения

### Основные компоненты
- `Pizzeria` - главный класс пиццерии
- `Order` - заказы с товарами
- `Customer` - клиенты с картами лояльности
- `Employee` - сотрудники (повара, официанты, водители, менеджер)
- `Menu` - меню с продуктами
- `Inventory` - склад ингредиентов
- `Payment` - система оплаты (наличные, карта, онлайн)
- `Delivery` - служба доставки

### Бизнес-логика
- Автоматический расчет стоимости доставки по адресу
- Система лояльности с накоплением баллов
- Различные стратегии ценообразования
- Проверка запасов ингредиентов
- Валидация заказов
- Генерация чеков
- Отслеживание доставки

## Требования
- Java 8 или выше
- Кодировка UTF-8 для корректного отображения русского текста
